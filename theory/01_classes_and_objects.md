# Classes and Objects

**A class** is a way to bundle related data and actions together into one
named "thing," instead of leaving them scattered as loose variables and
functions.

**An object** is one actual "built" thing made from that class — the class
is the blueprint, the object is the real item made from it.

## Real-world example
Think of a **Car**:
- Data it has: color, speed
- Actions it can do: drive, stop

A `Car` class bundles "color," "speed," "drive," and "stop" together as
one thing. The class itself is just the blueprint — it doesn't exist as
an actual car. When you say "make me a red Car," that specific red car is
an **object** (an instance) of the `Car` class. You can make many objects
(a red one, a blue one) from the same one class.

## One-line summary
Class = the blueprint. Object = an actual thing built from that blueprint.
