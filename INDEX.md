# LLD Learning Index

Each topic has a `theory/` file (plain-language notes, for revision) and a
`practice/` file (same name, for hands-on coding). `glossary.md` is separate
— it's the lookup for "what is X" C++ tool-questions (unique_ptr, virtual,
static, etc.), not LLD concepts themselves.
